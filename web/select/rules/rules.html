操作(C) 装備(E) 進行(P)

PC内部のダンジョンを進み、最終ボス mac_os.exe を撃退する。

メニュー

出撃前に、あなたのPCの中から最大3つのファイルを装備できます。
装備したファイルの拡張子に応じて、能力が上がった状態で出撃します。

どの拡張子で何が伸びるか

拡張子 ファイル1つあたりの上がり幅
.exe .dll .bat →
.txt .pdf .docx →
.png .jpg .bmp →
.mp3 .wav .flac →
.cpp .h .py .js →
.lnk .url →
.mp4 .avi .mkv →
.zip .7z .rar →
それ以外 →

同じ種類を3つ装備すれば3倍になります。 装備した結果は「パラメータ」ウィンドウで確認できます。

選び方の考え方

1種類で固めるほど、その能力が大きく伸びます。 迷ったら、まず .exe を3つ積んで攻撃力に寄せると分かりやすいです。
ファイルの中身は読み取りません。装備しても元のファイルは変化しません。

ゲームの流れ

  1. デスクトップの「ファイル選択」で、装備するファイルを最大3つ選ぶ
  2. 「難易度設定」で NORMAL / HARD を選ぶ
  3. 右下の「ゲームを開始 →」で出撃する

ダンジョンでやること

部屋にいる敵をすべて倒すと、次へ進めるようになります。 残りの敵の数は画面左上に出ています。
最後の部屋では mac_os.exe が現れます。これを倒せばクリアです。

拡張子を拾って付け替える

道中のブロックを壊すと拡張子の欠片が落ちます。拾ったものは E の持ち物にすべて溜まりますが、能力に乗るのは先頭の3つだけです。
白いリネーム端末の前で F2 を押すと、装備中のものと持ち物のものを ドラッグして入れ替えられます。持ち込んだ3つは道中では変えられません。

難易度

NORMAL 標準の敵の強さ。まずはこちらを推奨します。 HARD 敵が強化されます。手強い相手を求める人向けです。

やられたときは

体力が0になると失敗になります。装備を選び直して再挑戦できます。
